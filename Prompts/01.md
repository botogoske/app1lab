Crie uma página que lista diferentes tarefas.

Deve ser possível criar, editar e deletar tarefas.

Deve haver um formulário de criação de tarefas.

# Constraints

- Use React Hook Form com Zod para validar formulários.
- Use shadow/ui como biblioteca de componentes.
- Use Tailwind para estilização.
- Use Next.js App Router e TypeScript.

# MCPs

- Use Context7 para buscar documentação.
